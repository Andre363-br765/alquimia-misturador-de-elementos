### Um mini-projeto de alquimia feito para treinar HTML, CSS e JavaScript

Este projeto simula uma **loja de cartas / laboratório de alquimia**, onde o usuário pode clicar em elementos e ver combinações aleatórias.
Foi criado como exercício da *[Imersão Dev – Alura + Google](https://imersao.dev/)* para praticar:

* Organização de arquivos
* Manipulação do DOM
* JSON para armazenar dados
* Responsividade
* Uso de imagens e background

---

## ⚡ Tecnologias usadas

* **HTML5**
* **CSS3 (reset, estilos, responsivo, background cover)**
* **JavaScript (DOM + JSON)**
* **Fetch para carregar `data.json`**

## 🎮 Funcionalidades principais

* O usuário abre a página e os elementos carregam a partir de um arquivo **data.json**.
* Cada clique mostra uma **combinação aleatória**, como se fosse alquimia.
* O fundo usa uma imagem de laboratório ajustada com `background-size: cover`.
